# 本機回憶整理與靜態交付

這是一次性製作的工具。故事與原始照片留在這台電腦，公開網站只有精選展示圖片與文字。完成後不需要讓整理工具持續運行。

## 打開整理室

使用專案指定的 Node 版本：

```sh
nvm use
npm run editor
```

- 本機整理室：<http://127.0.0.1:5181/editor.html>
- 目前已儲存內容的觀看預覽：<http://127.0.0.1:5181/>
- 匯出後的成品預覽：<http://127.0.0.1:5181/export/>

第一次開啟會讀取已整理的 18 天行程。選擇旅行日及回憶，修改內容、加入照片，再按「儲存修改」。關閉工具或瀏覽器後，已儲存資料仍保留。

## 加入照片與故事

1. 選擇旅行日及回憶點，檢查回憶名稱、共同短文及旅伴補充。
2. 按「加入照片」，可一次選多張 JPEG、PNG 或 WebP。HEIC／RAW／Live Photo／影片目前不支援，請先轉為靜態 JPEG。
3. 工具保留匯入原檔，另產生長邊最多 480 px 的縮圖與 1,920 px 的瀏覽圖；不放大小圖。展示圖會轉正方向並移除 EXIF，原檔保持不變。
4. 拖曳排序或用前後按鈕移動。第一張就是代表照片；「設為封面」會移到第一張。可補照片描述與說明。
5. 「移除」只移除展示關聯，不刪除原始收藏。重複加入完全相同的檔案不會重複插入同一回憶。
6. 按「儲存修改」，看到成功訊息後再關閉。匯入、排序或改文字後，未儲存內容不會自動出現在正式匯出中。

位置還沒逐項確認的回憶會留在當日清單。確認精確位置後，可選「已確認冰島位置」，輸入「經度, 緯度」。沒有依據時保留「位置待確認」；航程與返家使用故事卡，不加入跨國路線。區域入口座標只代表選日期的範圍，並非實際回憶的精確座標。

## 匯出與保存

1. 儲存後，按「檢查待補項目」查看缺照片、缺位置與空白文字。
2. 按「匯出靜態網站」。工具會檢查圖片參照、內容格式及靜態檔案限制；損壞或遺失的圖片會阻擋匯出，主動留空的待補照片不會。
3. 按「開啟已匯出成品」檢查實際網站。只有匯出成功後，這個入口才有成品。
4. 完整可部署目錄是 `.local-memory/export/`。如需關閉整理工具後獨立預覽，可在終端機執行：

```sh
python3 -m http.server 5182 --bind 127.0.0.1 --directory .local-memory/export
```

接著開啟 <http://127.0.0.1:5182/>。這是一般靜態伺服器，不需要內容編輯 API；不要以直接雙擊 HTML 的方式驗收。

也可用命令重新匯出已保存內容：

```sh
npm run export:site
```

備份三樣東西：

- 自己原本的私人照片收藏；以及工具匯入後保存的 `.local-memory/originals/`。
- 完整 `.local-memory/` 工作目錄，包含故事清單、展示圖與保存版本。
- 最終 `.local-memory/export/` 靜態成品，可另外複製到備份磁碟。

`.local-memory/` 已排除版本控制與格式化。不要把整個工作目錄上傳到網站；只發布 `export/` 裡的內容。原始照片、編輯介面與本機服務不在成品中。匯出失敗時保留上一份可用成品。

## 觀看體驗

- 從區域入口選旅行日，或直接用下方日期選單。
- 點「當日回憶」可找到當天全部故事，包括位置待確認的項目。
- 手機點地圖封面先預覽，再點預覽開故事；桌機滑過／聚焦可看名稱。
- 照片可手動橫向翻閱，首末張的明確按鈕才會跨到上一段／下一段回憶；左右滑動與方向鍵都不自動跨回憶。
- 故事入口固定顯示在相簿標題下方，文字在內部展開。關閉保留地圖及旅行日。
- 網址會保留旅行日與回憶，可直接複製分享。底圖失敗時仍可從日期與清單讀故事。

## 尚待旅人提供

- 每段回憶至少一張真實照片，或明確接受該段暫時沒有照片。
- 照片順序、代表照片、想改成自己口吻的共同短文與旅伴補充。
- 私房瀑布、畫畫休息站、冰川集合點、晚宴、香水店、護照事件等補充；完整缺件以 [真實行程紀錄](itinerary.md) 為準。
- 已依公開來源補上 43 個具名景點參考點，對應 44 段回憶；來源見[定位查核紀錄](location-research.md)。這不是實際拍照／停車點或 GPS 軌跡，其餘未知位置仍需照片位置或旅人線索。

這些素材不影響先測試工具，但完整內容驗收與公開部署必須明確區分。現在的測試照片只存在隔離測試目錄，沒有當成旅程照片公開。

## 部署與已知界線

以 Cloudflare 免費靜態託管及免費網站網址為目標；正式發布時再確認當時額度與帳號登入。這次不需要 R2、Images、資料庫或線上內容後台。正式部署目前尚未執行，待真實素材驗收後再發布。

地圖仍需外部 OpenFreeMap 圖資與 WebGL；純靜態不代表完全離線，也不是對外部託管永久免費或永久可用的保證。

圖片處理採本機 [Sharp 圖片輸出](https://sharp.pixelplumbing.com/api-output/) 與[方向處理](https://sharp.pixelplumbing.com/api-operation/)能力，不呼叫付費雲端處理。
