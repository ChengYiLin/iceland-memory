# Domain Docs

本專案採 single-context：根目錄 `CONTEXT.md` 與 `docs/adr/`。

## 探索專案前

- 讀取根目錄 `CONTEXT.md`，以及 `docs/adr/` 中與當前工作相關的決策。
- 這些文件尚未存在時，直接繼續工作；由 `domain-modeling` 在術語或決策明確時逐步建立。

## 共用語彙

議題標題、實作、測試與說明使用 `CONTEXT.md` 定義的術語。遇到未定義的概念時，先確認是否為既有概念，或需要由 `domain-modeling` 補充的詞彙。

## 決策衝突

提案若與既有 ADR 衝突，明確指出該 ADR 與重新討論的理由。
