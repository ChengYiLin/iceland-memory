# 整合導覽與操作位置

## 完成行為

- 單一「旅程與回憶」入口取代旅行日與當日回憶兩個分散的選單。
- 從總覽開啟時顯示 18 個旅行日；選一天後，原面板直接顯示當日回憶。「全部旅行日」可返回清單，關閉面板後可繼續探索地圖。已選旅行日時，再次開啟入口會回到當日回憶。
- 航程、無座標的旅行日自動開啟同一面板；直接開啟回憶連結時只顯示相簿，避免 modal 疊加。
- 底部集中「全島總覽、前一天、旅程與回憶、後一天」。縮放移到左下角，按鈕尺寸為 44px；右上角不再放置旅程或地圖按鈕。
- 當日／整趟旅程的分享移到面板底部；單段回憶的分享放在相簿內文下方。成功與剪貼簿不可用時都有狀態訊息。
- 去回程入口也收進完整旅行日清單，移除地圖上額外的去回程工具列。既有地名標記、網址定位、照片待補狀態與內容均保留。

桌面使用側邊面板，手機使用底部面板；標題與底部操作固定，清單獨立捲動。選日後焦點移至回憶標題，關閉面板或相簿後回到固定入口。選日後面板保留開啟，關閉後才繼續操作地圖，是本次集中選取流程的取捨。

## 實作範圍

`JourneyMenu.vue` 取代 `DayMenu.vue`，另以 `journey-menu.css` 管理統一導覽樣式；`MemoryViewer.vue` 移除當日回憶的獨立狀態與面板，`JourneyCanvas.vue` 重設縮放位置與標記避讓區域，`MemoryAlbum.vue` 新增段落分享入口。清除不再使用的舊導覽 CSS，並更新既有端對端測試的操作方式，新增整合導覽測試。

沿用現有配色、字體與全幅地圖；這是操作區域的局部重編排，沒有抽取新方向、seed 或 redraw，也未新增素材或套件。
