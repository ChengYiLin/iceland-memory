# 回憶與精選照片組

每段回憶擁有一組依敘事順序排列的精選照片。回憶清單顯示前 3 張的照片組預覽與實際張數；地圖仍以代表照片定位，預覽補上照片總數。

相簿顯示大圖、照片進度與縮圖列，可點縮圖跳至任一張，也可使用按鈕、鍵盤、滑動或滑鼠拖曳翻閱。橫幅與直幅照片完整呈現，圖說跟隨照片。調整視窗寬度後維持所選照片，照片失敗仍能切換其他張。

「上一張／下一張」始終只翻閱同一組照片；在首末張停下，另外以固定的「上一段／下一段回憶」切換回憶，新回憶從首張開始。單張照片不顯示多圖操作，尚無照片則沿用既有狀態。

回憶切換固定在相簿底部；桌面相簿依多圖內容加高，小手機保留主要導覽標籤並精簡相鄰回憶的預覽文字。照片進度與縮圖選取在捲動結束時重新同步，避免中斷捲動後保留舊張數。

目前公開內容尚未補照片；使用瀏覽器攔截的多圖測試資料驗證，不寫入正式內容。驗收涵蓋 0、1、多張、末張邊界、縮圖、鍵盤、拖曳、尺寸改變、失敗圖片，以及手機版。
