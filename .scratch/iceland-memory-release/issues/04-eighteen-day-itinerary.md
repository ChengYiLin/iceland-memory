# 04: 完整 18 天行程與航程故事都能開啟

**What to build:** 旅人在本機與觀看網站都能找到完整 18 天的每個實際行程項目，航程及位置待確認的故事也有可開啟入口。

- [x] 將真實行程逐項整理為穩定回憶識別，包含子事件、住宿、餐廳與途中故事；18 天日期連續且對應來源，沒有沿用示範插畫或虛構敘事。
- [x] 完整日期選單、前後一天與當日清單可選取全部內容；航程使用故事卡，地圖維持冰島視野，零個或一個座標不產生虛構路線。
- [x] 只連接有依據的冰島位置，明確標示示意連線；未確認的正式地名、座標與文字保留待補狀態及位置線索，不用猜測補滿。
- [x] 暴雨未進場與隔日再訪分開；取消／未造訪更正不產生已到訪標記，求婚、彈跳床等子事件各自可開啟。
- [x] 交付每日項目與回憶的對照檢查；照片尚未供應的節點仍能編輯、預覽與閱讀，不把本張完成當作全部真實素材已驗收。
