# 03: 在本機批次整理每段回憶的照片與故事

**What to build:** 旅人能在本機選擇回憶，批次匯入一張或多張照片、排序、選封面及編輯說明；保存後輸出的內容與順序一致。

- [x] 依旅行日與回憶點切換，編輯名稱、位置線索、已確認座標／待確認狀態、共同短文與個別補充；缺照片仍能存故事，無效座標明確提示。
- [x] 支援 JPEG、PNG 與 WebP 批次加入，產生縮圖與瀏覽圖，處理方向、等比例尺寸與公開版本中繼資料；小圖不強制放大。
- [x] 拖曳排序、移除展示關聯、編輯替代文字與照片說明；指定封面移到第一張並保持其他照片相對順序，穩定識別不隨重排改變。
- [x] 清楚呈現處理進度、未儲存修改與保存結果，重開工具還原完整內容；移除展示關聯保留私人原檔，重新處理避免無限制重複輸出。
- [x] 以本機介面及輸出內容驗收批次、排序與持久化，不要求依賴 02 的最新版相簿；02 完成後，正式觀看自然讀取同一公開內容契約。
