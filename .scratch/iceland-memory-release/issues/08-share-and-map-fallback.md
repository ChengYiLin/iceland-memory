# 08: 分享指定回憶，底圖失敗仍能閱讀

**What to build:** 訪客可分享指定旅行日／回憶的連結；底圖未完成載入或失敗時，仍能從日期與當日清單閱讀故事。

- [x] 用穩定識別還原旅行日與回憶，重新整理與靜態託管皆可用；無效識別回到可操作的總覽或當日清單。
- [x] 故事與日期操作不依賴底圖成功載入，提供可辨識狀態與當日清單入口；圖片失敗仍可閱讀、關閉及繼續導覽。
- [x] 分享連結開故事後關閉，仍保留正確日期與可操作地圖狀態；不額外依賴後端路由或付費服務。
- [x] 延伸既有延遲底圖測試，驗證底圖完全失敗、有效／無效網址與桌機／手機閱讀，不假設外部圖資服務永遠可用。
