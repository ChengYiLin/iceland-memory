# 05: 同區多日與同位置回憶的選擇入口

**What to build:** 雷克雅維克、米湖等重複停留區域可先選旅行日，再探索當天內容；同日同位置的多段回憶也都能選取。

- [x] 內容中的區域關聯驅動總覽入口，數量按不同旅行日去重；同一天可從多區進入，區域入口不冒充回憶精確座標。
- [x] 桌機區域選單與手機底部面板顯示日序、日期與當日標題，選日後只顯示當天回憶與路線；無區域日仍可從完整日期選單進入。
- [x] 同日同座標打開故事選擇清單，跨日故事保持不同識別。相近但不同位置沿用避讓，不任意改動真實位置。
- [x] 同區換天在適合的視野內保持鏡頭，超出視野再重新定位；各入口的關閉、焦點與手機選取可用。
- [x] 以代表性重疊資料驗收即可，不必等 04 全量內容完成；完整 18 天整合時補齊真實資料的區域關聯。
