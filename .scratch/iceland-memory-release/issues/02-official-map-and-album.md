# 02: 正式首頁採用 A 的地圖與照片故事體驗

**What to build:** 一般首頁與正式成品呈現最新版 A，觀看者能選日、看示意路線、打開故事、手動翻照片並回到原位置繼續探索。

- [x] 全螢幕地圖、浮動日期控制、約 2.5 秒過場與自由探索；過場中可開故事，快速換天只保留最後一次選擇，支援減少動態效果。
- [x] 正式相簿支援零張、單張與多張照片、直橫幅、原生滑動、滑鼠拖曳及方向鍵；跨回憶只由按鈕觸發，首末張與當天最後一段行為符合規格。
- [x] 固定外框、可見故事入口與 ×、內部長文捲動及兩種導覽按鈕層級；關閉保留日期與地圖狀態，支援鍵盤、焦點與手機小畫面。
- [x] 桌機封面 hover／focus、手機單張預覽與再次點擊開故事，換天清空預覽；同日相近標記避讓，鏡頭移動不拉長舊位置連線，保留圖資署名。
- [x] 照片失敗仍可看文字與導覽，按需要載入瀏覽圖；正式輸出沒有原型版本切換及除錯面板。使用小型多日測試內容驗收，不等待全部真實資料。
- [x] 更新既有桌面／手機 Playwright 斷言至正式互動，保留真實 WebGL 的外部底圖隔離方式。
