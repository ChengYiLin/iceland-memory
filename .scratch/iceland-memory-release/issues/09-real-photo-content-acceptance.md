# 09: 完成真實照片的 18 天整合與內容驗收

**What to build:** 把旅人交付的真實照片透過本機工具整理到全部故事節點，產出完整、可驗收的 18 天靜態成品。

- [ ] 對照真實行程檢查每個實際項目及子事件都有入口，補齊區域關聯與有依據的位置；不為了結案刪除待確認故事或猜測資料。
- [ ] 真實照片逐節點匯入、排序與選封面；每個預定故事至少一張照片，未補齊項目必須明列並由旅人明確接受，不以測試素材代替。
- [ ] 用夜景、人物及直橫幅照片檢視展示品質、手機載入與標記密度；完整驗收單張／多張、長故事、重疊日、航程與末日邊界。
- [ ] 執行從匯入、儲存重開、匯出到停止編輯服務後靜態觀看的整合流程，以及相應既有必要檢查。

## 外部條件

**外部素材條件：** 本張的最終內容完成需旅人提供照片與必要回憶補充。素材未齊時列出缺件並保留任務未完成，不影響前八張技術功能驗收；不把等待素材當作程式任務的虛構阻擋邊。
