## 第三輪：橫向滑動照片與跨回憶邊界

使用者希望過場 2–3 秒、照片可橫向滑動，並詢問如何從第一段 3 張銜接第二段 5 張。

過場調為 650 ms 鏡頭 + 1850 ms 路線。建議先試回憶內原生橫向捲動／觸控滑動、滑鼠拖曳，最後一張停留，再由包含封面、名稱、照片數的按鈕前往下一段。不以持續滑動自動跨回憶；漸層只是邊緣提示。保留方向鍵與箭頭，垂直滾輪不攔截為翻頁。

跨回憶方案目前是建議原型，尚待使用者選定。第一段 3 張、第二段 5 張，進入下一段重設為第一張；上一段入口同樣回到第一張；最後一段提供回地圖。

第三輪操作檢查：桌機拖曳到第 2／3 張，橫向捲動到第 3／3 張，繼續捲動仍停留第一段；點下一段後為第 1／5 張，方向鍵可繼續翻看。手機觸控模擬依序滑到第 2／3、第 3／3，再滑仍停留；明確切換後為第 1／5。最後一段的末張提供回地圖入口。桌機操作未出現 pageerror，型別檢查通過。照片皆為插畫，尚未用真實手機與真實照片驗證手感。

## 第四輪：地圖問題與導覽合併

使用者回報 OpenFreeMap 標示在手機顯眼、鏡頭過場出現長線，並要求第一張也能回上一回憶、縮減底部操作區。

重現命令：使用 Node 22 執行 `/private/tmp/iceland-leader-repro.mjs`（隔離 Playwright Chromium）。修正前量到最長 451 px 的標記連線，手機圖資標示為展開。原因是標記避讓以舊視角計算連線，鏡頭縮放時放大該地理線段。修正為鏡頭移動時清除舊偏移與連線，moveend 後再計算。

手機圖資來源改為預設收合的資訊按鈕，仍保留來源連結且可手動展開。相簿改為單列導覽：中間張翻照片；第一張左側回上一段末張；末張右側去下一段首張；最後一段則回地圖。保留原生滑動，不因滑到底自動跨回憶。
