# 已核准的正式實作任務拆分

2026-10-24 使用者確認粒度與相依關係後，已發布 [10 張正式任務](../iceland-memory-release/README.md)。本文件保留核准的拆分與驗收依據，需求以[正式規格](spec.md)為準。

既有原型任務保持原狀。正式任務已另外發布至 `.scratch/iceland-memory-release/issues/`，從 01 起編號，每張獨立一個檔案並標記 `ready-for-agent`，沿用既有正式規格作來源，不複製第二份規格。

## 拆分原則

- 每張交付可操作的完整行為，包含必要的內容契約、本機讀寫或圖片處理、畫面與外部行為測試；不拆成單獨的資料層、API 層與畫面層任務。
- 第一張只做一段回憶、單張照片的完整流程，讓後續修改有可重現的驗收入口。只做支援此流程所需的最小前置整理，維持既有功能與檢查可用，不另開沒有使用者成果的廣泛重構。
- 每張沿用正式規格的來源、範圍與外部行為驗收。原型是體驗參考，不能將其虛構內容轉為真實旅程；測試照片必須明確作為測試素材。
- 以下只列直接阻擋關係；由相依任務間接繼承的前置任務不重複列出。無須因為任務編號在前就等待。
- 01 完成後，02 與 03 都具備開工條件；02 完成後，04、05、08 各自具備開工條件；03 完成後，06、07 各自具備開工條件。這是依賴關係描述，不要求多代理同時實作。
- 真實照片與未確認地點是外部素材條件，與程式任務的阻擋邊分開記錄。前八張可用可公開的測試素材及明確待補狀態驗收，不用等待全部私人照片到齊。

## 01：一段回憶從本機編輯到靜態觀看

**Blocked by:** None（可立即開始）。

**What it delivers:** 以 Day 6 的一段真實回憶建立最小完整流程：在本機修改故事、加入一張照片，儲存、重開並匯出，關閉工具後仍能從靜態成品閱讀。

- 最小本機瀏覽器介面提供一段回憶的文字儲存與單張 JPEG 匯入，原檔私下保存，產生縮圖與瀏覽圖。未取得真實照片時以明確的測試素材驗收，不公開冒充真實回憶。
- 共用穩定的旅行日／回憶／照片識別與可驗證內容契約；支援已知、待確認與航程位置狀態的擴充，原始路徑不混入公開內容。
- 儲存到本機檔案後重開可還原；失敗保留上一份有效內容。本機服務只監聽 loopback，限定工作目錄與可信任寫入來源，原檔不被覆寫。
- 提供最小匯出與靜態預覽；停止編輯服務後，故事與展示圖片仍可由一般靜態伺服器讀取。輸出排除編輯介面、寫檔服務、原檔與草稿。
- 沿用既有觀看骨架完成這條切片，不要求本張同時完成全部 A 體驗、批次匯入或完整 18 天。建立可重複的高層整合驗收，不測內部函式呼叫。

**規格覆蓋:** User Stories 35、42、44–46、49–51 的最小完整流程；後續任務完成其全量與失敗情境。

## 02：正式首頁採用 A 的地圖與照片故事體驗

**Blocked by:** 01。

**What it delivers:** 一般首頁與正式成品呈現最新版 A，觀看者能選日、看示意路線、打開故事、手動翻照片並回到原位置繼續探索。

- 全螢幕地圖、浮動日期控制、約 2.5 秒過場與自由探索；過場中可開故事，快速換天只保留最後一次選擇，支援減少動態效果。
- 正式相簿支援零張、單張與多張照片、直橫幅、原生滑動、滑鼠拖曳及方向鍵；跨回憶只由按鈕觸發，首末張與當天最後一段行為符合規格。
- 固定外框、可見故事入口與 ×、內部長文捲動及兩種導覽按鈕層級；關閉保留日期與地圖狀態，支援鍵盤、焦點與手機小畫面。
- 桌機封面 hover／focus、手機單張預覽與再次點擊開故事，換天清空預覽；同日相近標記避讓，鏡頭移動不拉長舊位置連線，保留圖資署名。
- 照片失敗仍可看文字與導覽，按需要載入瀏覽圖；正式輸出沒有原型版本切換及除錯面板。使用小型多日測試內容驗收，不等待全部真實資料。
- 更新既有桌面／手機 Playwright 斷言至正式互動，保留真實 WebGL 的外部底圖隔離方式。

**規格覆蓋:** User Stories 2–7、18–19、21–34。

## 03：在本機批次整理每段回憶的照片與故事

**Blocked by:** 01。

**What it delivers:** 旅人能在本機選擇回憶，批次匯入一張或多張照片、排序、選封面及編輯說明；保存後輸出的內容與順序一致。

- 依旅行日與回憶點切換，編輯名稱、位置線索、已確認座標／待確認狀態、共同短文與個別補充；缺照片仍能存故事，無效座標明確提示。
- 支援 JPEG、PNG 與 WebP 批次加入，產生縮圖與瀏覽圖，處理方向、等比例尺寸與公開版本中繼資料；小圖不強制放大。
- 拖曳排序、移除展示關聯、編輯替代文字與照片說明；指定封面移到第一張並保持其他照片相對順序，穩定識別不隨重排改變。
- 清楚呈現處理進度、未儲存修改與保存結果，重開工具還原完整內容；移除展示關聯保留私人原檔，重新處理避免無限制重複輸出。
- 以本機介面及輸出內容驗收批次、排序與持久化，不要求依賴 02 的最新版相簿；02 完成後，正式觀看自然讀取同一公開內容契約。

**規格覆蓋:** User Stories 35、37–46。

## 04：完整 18 天行程與航程故事都能開啟

**Blocked by:** 02。

**What it delivers:** 旅人在本機與觀看網站都能找到完整 18 天的每個實際行程項目，航程及位置待確認的故事也有可開啟入口。

- 將真實行程逐項整理為穩定回憶識別，包含子事件、住宿、餐廳與途中故事；18 天日期連續且對應來源，沒有沿用示範插畫或虛構敘事。
- 完整日期選單、前後一天與當日清單可選取全部內容；航程使用故事卡，地圖維持冰島視野，零個或一個座標不產生虛構路線。
- 只連接有依據的冰島位置，明確標示示意連線；未確認的正式地名、座標與文字保留待補狀態及位置線索，不用猜測補滿。
- 暴雨未進場與隔日再訪分開；取消／未造訪更正不產生已到訪標記，求婚、彈跳床等子事件各自可開啟。
- 交付每日項目與回憶的對照檢查；照片尚未供應的節點仍能編輯、預覽與閱讀，不把本張完成當作全部真實素材已驗收。

**規格覆蓋:** User Stories 1、3、8–11、16、36、38、43。

## 05：同區多日與同位置回憶的選擇入口

**Blocked by:** 02。

**What it delivers:** 雷克雅維克、米湖等重複停留區域可先選旅行日，再探索當天內容；同日同位置的多段回憶也都能選取。

- 內容中的區域關聯驅動總覽入口，數量按不同旅行日去重；同一天可從多區進入，區域入口不冒充回憶精確座標。
- 桌機區域選單與手機底部面板顯示日序、日期與當日標題，選日後只顯示當天回憶與路線；無區域日仍可從完整日期選單進入。
- 同日同座標打開故事選擇清單，跨日故事保持不同識別。相近但不同位置沿用避讓，不任意改動真實位置。
- 同區換天在適合的視野內保持鏡頭，超出視野再重新定位；各入口的關閉、焦點與手機選取可用。
- 以代表性重疊資料驗收即可，不必等 04 全量內容完成；完整 18 天整合時補齊真實資料的區域關聯。

**規格覆蓋:** User Stories 13–17、20，並延伸 32、34 至新增入口。

## 06：照片與儲存失敗可辨識、可恢復

**Blocked by:** 03。

**What it delivers:** 遇到壞圖、未支援格式或寫檔失敗時，旅人知道受影響項目，能保留成功內容並修正後重試。

- 混合有效、損壞與不支援格式的批次匯入，逐檔回報結果；不因單檔失敗毀損其他已保存回憶或原檔。
- 文字、照片關聯與圖片輸出保存中失敗時，保留上一份可用版本；錯誤指明受影響旅行日／回憶／檔案，修正後可重試。
- 未儲存離開提醒與失敗後重開行為一致，不能顯示保存成功卻遺失內容；重複匯入、重試或重新處理不改變既有封面與順序。
- 透過完整操作入口與隔離工作目錄驗收，不以大量內部 mock 或測試實作細節取代實際檔案結果。

**規格覆蓋:** User Stories 42、44、47 與保存／圖片處理的失敗驗收。

## 07：檢查內容並匯出可靠的靜態成品

**Blocked by:** 03。

**What it delivers:** 旅人能看見待補清單與匯出錯誤，預覽可部署成品；成功匯出後可關閉工具並獨立觀看。

- 從已保存版本匯出，未儲存內容有明確處置；區分缺照片／位置的可接受待補狀態與遺失已引用檔案的損壞狀態。
- 重複識別、無效內容、失效圖片參照及超出檔案數／單檔限制阻擋匯出，提供可定位錯誤；顯示缺圖、缺位置及待補文字清單。
- 正式成品預覽不依賴編輯 API；停止工具後靜態網站的圖片與故事仍可讀，瀏覽器沒有 localhost 編輯服務請求。
- 輸出排除編輯介面、私人原檔、草稿與本機絕對路徑；匯出失敗保留上一份有效成品，重複匯出不污染私人收藏。
- 成品檢查可透過小型測試資料觸發上限及失效參照，不需實際產生或上傳大量圖片。

**規格覆蓋:** User Stories 48–52 與靜態交付的失敗驗收。

## 08：分享指定回憶，底圖失敗仍能閱讀

**Blocked by:** 02。

**What it delivers:** 訪客可分享指定旅行日／回憶的連結；底圖未完成載入或失敗時，仍能從日期與當日清單閱讀故事。

- 用穩定識別還原旅行日與回憶，重新整理與靜態託管皆可用；無效識別回到可操作的總覽或當日清單。
- 故事與日期操作不依賴底圖成功載入，提供可辨識狀態與當日清單入口；圖片失敗仍可閱讀、關閉及繼續導覽。
- 分享連結開故事後關閉，仍保留正確日期與可操作地圖狀態；不額外依賴後端路由或付費服務。
- 延伸既有延遲底圖測試，驗證底圖完全失敗、有效／無效網址與桌機／手機閱讀，不假設外部圖資服務永遠可用。

**規格覆蓋:** User Stories 11–12、54，並驗證 30–31 的失敗情境。

## 09：完成真實照片的 18 天整合與內容驗收

**Blocked by:** 04、05、06、07、08。

**What it delivers:** 把旅人交付的真實照片透過本機工具整理到全部故事節點，產出完整、可驗收的 18 天靜態成品。

- 對照真實行程檢查每個實際項目及子事件都有入口，補齊區域關聯與有依據的位置；不為了結案刪除待確認故事或猜測資料。
- 真實照片逐節點匯入、排序與選封面；每個預定故事至少一張照片，未補齊項目必須明列並由旅人明確接受，不以測試素材代替。
- 用夜景、人物及直橫幅照片檢視展示品質、手機載入與標記密度；完整驗收單張／多張、長故事、重疊日、航程與末日邊界。
- 執行從匯入、儲存重開、匯出到停止編輯服務後靜態觀看的整合流程，以及相應既有必要檢查。
- **外部素材條件：** 本張的最終內容完成需旅人提供照片與必要回憶補充。素材未齊時列出缺件並保留任務未完成，不影響前八張技術功能驗收；不把等待素材當作程式任務的虛構阻擋邊。

**規格覆蓋:** User Stories 1、9–10、36、39–46、49、52 的完整真實內容，以及正式規格最終內容驗收。

## 10：零成本靜態部署與最終封存交付

**Blocked by:** 09。

**What it delivers:** 將驗收完成的靜態成品發布到免費網站網址，交付可重現的操作說明與完整備份，完成本次一次性專案。

- 部署前核對當時 Cloudflare 免費靜態託管規則及成品大小、檔案數，使用免費提供的網址；不開通 R2、Images、資料庫、新購網域或付費方案。
- 部署完整靜態成品，線上選日、讀故事、圖片及分享連結可用；本機工具關閉時線上網站仍正常，不依賴本機服務或排程同步。
- 留存私人原檔、已保存內容與最終公開靜態成品，提供本機啟動、匯入／儲存、匯出／預覽、重新部署與封存說明。
- 記錄外部底圖與託管仍是運行條件，不承諾完全離線或永久免費；不引入上線後額外內容營運需求。
- **外部帳號條件：** 部署時需可用的 Cloudflare 帳號與授權環境；如遇僅使用者能完成的登入或開通步驟，在完成可部署成品後再具體處理。

**規格覆蓋:** User Stories 50–53 與公開交付。

## 覆蓋與前沿檢查

- 01–10 的規格覆蓋合計包含全部 54 條 User Stories；共通可及性、原檔保護與失敗處置在各自操作入口驗收，不等到最後才補。
- 01 是唯一可立即開始的正式任務；後續僅在直接阻擋任務完成後進入可執行前沿。
- 使用者已確認粒度與阻擋邊，正式任務已逐張發布；沒有修改或關閉既有原型任務或正式規格。
