# 整合旅程導覽

將旅行日與當日回憶收進同一個「旅程與回憶」面板。從總覽開啟時先列出所有旅行日；已選旅行日時直接顯示當日回憶。選一天後面板保留開啟並顯示回憶，可返回旅行日清單或關閉面板看地圖。開啟相簿前先關閉導覽面板，避免兩個 modal 疊加。

全島總覽、前一天、面板入口、後一天集中在底部工具列；分享收進面板。右上角移除旅程按鈕，地圖縮放移至左下角，與來源標示、文字和底部導覽保持間距。品牌按鈕仍可返回總覽。

桌面面板從側邊開啟，手機使用底部面板；內容區獨立捲動，標題與必要操作固定。選擇日期後焦點移至回憶標題，Escape 關閉面板後返回固定入口。無座標、航程與底圖載入失敗時，回憶仍可由同一面板閱讀。

保留既有旅程與照片資料、URL 分享定位、地名優先的地圖入口與手動探索。照片待補為已知內容狀態，不在本次修正範圍。

驗收：總覽、旅行日清單、當日回憶、相簿、返回總覽；前後一天邊界；分享成功與失敗訊息；鍵盤焦點與 Escape；1440、768、390 及 320px 無水平溢出或操作遮擋。

## 導覽層級調整

旅行日清單以月／日作為主要辨識，附上「第幾天」；清單標題明確顯示「全部旅行日」。進入當日後，以深綠標題區與醒目的「9月28日的回憶」區分回憶層級，保留返回全部旅行日的操作。

移除公開內容的「行程更正」整理註記；匯入及匯出不再將該類文字帶進公開資料，回憶故事與照片維持原樣。關閉按鈕使用置中的 SVG，維持 44px 操作範圍。
