# PROTOTYPE：兩天回憶點與照片故事

這份可拋棄原型回答：哪種布局讓兩位旅人更容易停下來回憶？它不代表正式設計。

最新回饋已收斂到 A：全螢幕地圖與浮動選單，鏡頭 650 毫秒、路線 1850 毫秒快速帶過，不自動逐站展示預覽。直接點回憶標記看照片故事，關閉後繼續自由探索。A 左下角「⋯」可展開舊版比較工具與原型狀態；B／C 保留前一輪設計與慢節奏供參考。

## 開啟

使用專案指定的 Node（`nvm use`），執行 `npm run prototype`。瀏覽器會開啟 <http://127.0.0.1:5180/?variant=A>。

| 版本           | 網址參數     | 結構與取捨                                                                 |
| -------------- | ------------ | -------------------------------------------------------------------------- |
| A 地圖上的片刻 | `?variant=A` | 新版全螢幕地圖與浮動選單；快速過場後自行點回憶。                           |
| B 攤開旅行手帳 | `?variant=B` | 桌面左右並排、手機上下分區；回憶名稱、代表照片、短文更突出，地圖空間較小。 |
| C 沿途照片帶   | `?variant=C` | 地圖下方排列七張代表照片；容易跳到想看的回憶，畫面資訊量較多。             |

底部箭頭或鍵盤左右鍵切換版本，網址同步更新。切換保留旅程進度，重新整理回到總覽。相簿開啟時左右鍵只翻照片。按 Escape 或「回到地圖」關閉。

## 試看流程（新版 A）

1. 點地圖上的 DAY 01，或「走進第 1 天」。地圖一直鋪滿視窗，所有控制浮在地圖上。
2. 鏡頭快速定位、路線短暫展開，約 2.5 秒後停留探索；不自動逐站切換照片預覽。
3. 隨時點數字標記，直接打開該回憶的照片故事。若過場仍未完成，就立即完成路線。
4. 同一段回憶內橫向滑動照片；桌機可拖曳、觸控板橫向捲動，也保留箭頭與方向鍵。Day 01 第一段 3 張、第二段 5 張，包含直幅插畫。Day 02 則有 5 段不同的示範回憶。最後一張保持停留，需要時展開共同短文。
   最後一張右側改為「下一段回憶」，點擊才進入下一段第 1 張；第一張左側可回上一段的最後一張。最後一段的右側提供回地圖。
5. 按 Escape 或「回到地圖」關閉，回到原本地圖位置自由探索。
6. 在手機試選後兩個靠近的點；標記會簡單錯開並以細線連回位置，也可放大地圖。
7. 左下角「⋯」打開比較工具，再用箭頭查看上一輪 B／C（仍有慢速導覽與沿途預覽）。

「原型狀態」顯示版本、旅行日、播放階段、進度、已到達點、預覽、相簿與照片索引。初次載入和切換版本也輸出狀態至 console。資料全在記憶體，只有版本記在網址；沒有上傳、資料庫或 Google 相簿連線。

## 邊界與後續

- 故事、同伴對話與一天七站的安排皆為虛構示範；以本機 SVG 插畫佔位，不能用來判斷真實照片的情感效果或載入速度。
- 路線是示意連線，不是駕車道路或旅人實際軌跡。外部底圖沿用 OpenFreeMap。
- 現在提供 Day 01（南岸 7 點）與 Day 02（東南岸 5 點）。底部箭頭、日期選單、總覽標記都可選天，換天重新播放約 2.5 秒過場並停留探索；18 天完整內容尚未加入。原型的 Day 01／02 是示範編號，對應真實旅行日的內容仍以 [真實行程紀錄](../../../../docs/itinerary.md) 為準。
- 遵循減少動態效果偏好時直接探索。
- 只有開發模式可載入原型；一般首頁與正式建置保持既有畫面。
- 已選定全螢幕地圖的方向，A 為最新修訂，尚待使用者試看。實作任務與待確認項目在 `.scratch/memory-experience/issues/01-seven-memory-prototype.md`。
- 使用者選定後才記錄體驗結論、改寫正式實作，並把完整原型封存至 throwaway branch。目前專案尚無 Git，未建立或宣稱已有封存分支。

## 最新相簿操作

照片維持原生橫向滑動、滑鼠拖曳與方向鍵操作。下方只有一列：

- 中間張：`上一張 ← | 張數 | → 下一張`。
- 第一張：左側改為「上一段回憶」，回到上一段最後一張；第一段則停用左側。
- 最後一張：右側改為「下一段回憶」，進到下一段第一張；最後一段則是「回到地圖」。

上一段入口與額外的下一段封面卡已併入同一列。橫向滑動和方向鍵仍只翻照片，不會自動跨越回憶；跨回憶需明確點擊按鈕。

## 地圖修正

手機圖資來源預設收合為資訊按鈕，使用者仍可展開來源連結。標記避讓短線在鏡頭移動時清除、定位後重新計算，避免舊視角的連線被縮放拉長。過場維持約 2.5 秒。

## Day 02 與來源標示

- Day 02 從維克往東至冰河湖、赫本，全部是虛構示範故事與示意連線。
- 原型依選定旅行日更新路線、標記、照片故事中的日期與回憶總數；跨回憶只在當天內前後切換。
- 兩天可快速來回切換，會取消上一段鏡頭與重設播放進度。
- 關閉按鈕顯示「×」，保留可及性標籤；終點導覽使用「關閉」。
- 依 OpenFreeMap 官方 https://openfreemap.org/#attribution 可移除 OpenFreeMap 品牌；已在載入樣式時保留 OpenMapTiles 與 OpenStreetMap 來源，省略 OpenFreeMap 品牌。不是把整個圖資來源控制隱藏。
- 共同短文已採使用者選定的固定外框方案：標題、關閉按鈕固定，照片與短文在內部捲動。展開時平順帶到文字，不再改變彈窗高度。

## 第六輪：辨識回憶與看見故事

- 相簿標題下方有固定的暖色故事入口，含第一句短文與讀故事提示；不用先捲到底部。完整故事在內容區頂端展開，保持彈窗尺寸及關閉按鈕位置。
- 照片按鈕採描邊、圓角、單箭頭；換回憶採深綠實心、較方的外觀、雙箭頭，維持同一列控制。
- 桌機每個點顯示約 52 px 小封面及序號；hover／focus 看名稱與地點，一次只顯示當前的標籤。
- 手機每個點顯示約 38 px 圓形封面及序號，單次點擊顯示一張預覽卡，再點卡片開故事（再次點同一標記也可直接開啟）。卡片可關閉，換天時會清除。這是本輪供評估的方案。
- 地圖使用示範插畫；已分配不同色調以區分點位，辨識實際旅行回憶的效果仍要換成你們的真實封面再看。
